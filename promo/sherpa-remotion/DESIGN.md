# Sherpa Promo Visual Identity

## Style Prompt
Suzuka Design System applied to a security-engineering promo: precision, kinetic restraint, single racing-line accent, dense evidence cards, and direct pit-wall language. The film should feel like an operational interface for vulnerability discovery, not a generic SaaS montage.

## Colors
- Suzuka Green `#006941`: the only primary accent and the through-line for meaning.
- Light surfaces: `#f6f6f6`, `#ffffff`, `#f0f1f1` style neutrals.
- Night surfaces: semantic inversion only; accent remains `#006941`.
- Supporting tones are restrained: amber for caution, red for verifier risk, blue for orchestration reference.

## Typography
- Display / body: `Inter`-style dense grotesk.
- Labels: `Space Grotesk`-style uppercase technical labels.
- Code labels: `JetBrains Mono`, `SFMono-Regular`, `Menlo`, monospace

## Motion
- 150 ms to 500 ms measured transitions, cubic-bezier style easing.
- No bounce or overshoot.
- Animate opacity and transform only.
- Keep scenes dense; avoid long single-title holds.
- Use 1 px speed lines and card shifts to imply movement without visual noise.
- Apple-style layer choreography is allowed: soft ease-out, subtle camera glide, blur-to-sharp entry, and staggered content reveals.
- Scene transitions should feel like keynote slides moving through depth, not web hover effects.

## Geometry
- Prefer hard 1 px strokes, orthogonal layouts, and 4-8 px radius.
- Use a 4 px Suzuka Green left border to anchor cards and callouts.
- Avoid large rounded pills except where the source system explicitly calls for compact chips.
- Avoid decorative gradients; surfaces should read as semantic planes, not glass panels.

## What NOT to Do
- Do not use generic purple-blue startup gradients.
- Do not present fuzzing as magic; show the stages and evidence loop.
- Do not use random card grids without hierarchy.
- Do not imply run/repro uses AI to alter verification results.
- Do not let sparse cinematic pauses create empty black frames.
- Do not use soft glassmorphism, large glows, or large circular ornaments.
